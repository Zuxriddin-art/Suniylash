# Suniylash

Website for **Suniylash**: cinematic AI video ads for brands.

- One static page (`index.html`) with Uzbek, Russian and English.
- Orders are sent to Telegram ([@suniylash](https://t.me/suniylash)); Instagram: [@suniylash](https://instagram.com/suniylash).
- Prices, Telegram/Instagram usernames and videos are set in the `CONFIG` block at the top of the script in `index.html`.

Hosted with GitHub Pages (Settings → Pages → Deploy from branch `main`, folder `/ (root)`).
